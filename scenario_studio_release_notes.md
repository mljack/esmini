## scenario studio release notes

### 2025-12-06 Version 0.1.2

Improvements and fixes:
- Simplify the UI workflow when creating nodes, by only showing "Create Node" dialog when there are some conflicted nodes to be removed for new-created nodes.
- Try to load the OpenDRIVE file after OpenSCENARIO is loaded. If failed to find the OpenDRIVE file, ask users to select it manually.
- Support choosing filepath/path with a file dialog.
